How the motion propagates

  1. Actuator → screw. Rotation only; thrust bearings locate the screw axially.
  2. Screw → nut. One lead of axial travel per revolution.
  3. Nut → arm 1. The nut pin rides in a slot aligned with arm 1, so the pivot-to-nut distance r₁ changes freely as the arm swings.
  4. Arm 1 → arm 2. Both arms are one rigid body about the fixed bearing, so φ = θ − β at every instant.
  5. Arm 2 → jaw. A second slider bearing in arm 2's slot carries the jaw along the linear rail.
  6. Mirrored pair. Identical arms on both sides give symmetric, self-centring jaws.

The pins move along their slots as well as with them, converting translation → rotation → translation. The transmission ratio changes across the stroke, so grip force changes with jaw speed.
